## 启用 WebNN

> <InfoIcon /> Windows ML / OpenVINO Execution Provider 需要 Windows 11 24H2 或更高版本才能运行

<Steps>
### 安装最新的 [Chrome Canary](https://google.com/chrome/canary) 或 [Edge Canary](https://www.microsoft.com/en-us/edge/download/insider?form=MA13FJ)
### 在浏览器地址栏中打开 `about://flags`
### 搜索 `Enables WebNN API` 并将其改为 `Enabled`
### 重新启动浏览器
</Steps>

## 在 LiteRT 后端（CPU 和 GPU）上运行 WebNN

> <InfoIcon /> 适用于 24H2 之前的 Windows 11 版本、Windows 10 和 Linux

<Steps>
### 在浏览器地址栏中打开 `about://flags`
### 搜索 `ONNX Runtime backend for WebNN` 并将其改为 `Disabled`
### 重新启动浏览器
</Steps>
